# 런칭 전 QA 체크리스트 (Release Regression)

목표: 기능이 많아진 상태에서 **배포 전 핵심 흐름이 깨지지 않았는지** 빠르게 확인한다.

가이드:
- **P0**: 런칭 차단(로그인/홈/핵심 플로우/데이터 쓰기/결제급 수준). 하나라도 실패하면 배포 중단.
- **P1**: 핵심 경험 훼손(전환/CTR/추천 노출, 주요 화면 사용 불가). 가능하면 배포 전 수정/롤백 판단.
- **P2**: 미관/경고/엣지 케이스. 배포 후 핫픽스/다음 스프린트 처리 가능.

테스트 원칙:
- 모바일/데스크톱 최소 1회씩(특히 Home 상단 레일/스크롤/모달).
- **콘솔 에러 0**을 목표로 하되, “known warning”이 있는 경우는 아래 “반드시 볼 에러 목록” 기준으로 판단.
- 네트워크는 DevTools에서 **실패(4xx/5xx), 과도한 반복 호출**, 응답 지연을 확인.
- A/B/관측 로그는 “best-effort”라 UI를 막지 않아야 한다(실패해도 화면/클릭이 멈추면 안 됨).

---

## 0) 배포 전 준비 (환경/데이터)

- **P0 | 빌드 확인**
  - **방법**: 로컬/CI에서 `npm run build` 성공 확인
  - **기대 결과**: 빌드 성공, 런타임 에러 없이 진입 가능

- **P0 | Supabase 마이그레이션 적용 여부**
  - **방법**: 아래 테이블/컬럼 존재 확인(운영/스테이징)
  - **기대 결과**: 테이블/컬럼이 존재하고 RLS로 INSERT/SELECT가 기대대로 동작
  - **체크 대상**
    - `collection_interaction_logs`
    - `home_section_impression_logs`
    - `collection_interaction_logs.experiment_bucket`
    - `home_section_impression_logs.experiment_bucket`

## 1) 비로그인 홈 (Guest Home)

- **P0 | 홈 진입/첫 렌더**
  - **방법**: 로그아웃 상태에서 `/` 진입
  - **기대 결과**
    - 화면이 즉시 렌더되고 빈 화면/무한 로딩 없음
    - 검색바 입력/제출 가능

- **P0 | Home 상단 레일 노출**
  - **방법**: Home 상단에서 스크롤/대기(레일 lazy mount 확인)
  - **기대 결과**
    - “지금 뜨는 코스”가 로딩 후 노출(없으면 섹션이 숨김 처리)
    - Guest는 “공개 컬렉션 레일”이 노출(활동 피드는 더보기에서만 노출될 수 있음)

- **P1 | A/B bucket에 따른 레이아웃 차이**
  - **방법**: 새 시크릿 창 2~3회(또는 localStorage 초기화)로 Home 상단 순서 확인
  - **기대 결과**
    - 일부 세션은 “활동/공개 레일 우선”, 일부는 “상황 rail 우선”
    - 레이아웃이 달라도 클릭/네비게이션/스크롤이 정상

- **P1 | 섹션 노출 로그(best-effort)**
  - **방법**: 섹션이 실제로 viewport에 들어오도록 스크롤
  - **기대 결과**
    - UI는 로그 성공/실패와 무관하게 정상 동작
    - 네트워크에 `home_section_impression_logs` insert 요청이 발생할 수 있음(실패해도 사용자 흐름 영향 없음)

## 2) 로그인 홈 (Auth Home)

- **P0 | 로그인 후 홈 진입**
  - **방법**: 로그인 → 홈 진입
  - **기대 결과**
    - 로그인 상태 UI(프로필/저장/픽 관련)가 정상 노출
    - 홈 상단 토글/더보기/모달이 에러 없이 동작

- **P0 | HomeScope 토글(전체/픽한 사람)**
  - **방법**: 상단 “전체/픽한 사람” 토글 전환
  - **기대 결과**
    - 활동 피드/공개 레일의 followed bias가 토글에 맞게 바뀜
    - 전환 시 UI 멈춤/무한 로딩/중복 fetch 폭주 없음

- **P1 | 개인화 섹션 lazy mount**
  - **방법**: Home 상단 영역에서 스크롤하며 개인화 섹션이 나오는지 확인
  - **기대 결과**
    - “내 취향 기반 추천”, “취향이 비슷한 사람” 등 섹션이 필요할 때만 로드
    - 로그인/저장 시그널이 없으면 섹션이 숨김 처리

- **P1 | 섹션 노출/클릭 로그**
  - **방법**: 레일이 보이는 상태에서 카드 클릭
  - **기대 결과**
    - `home_section_impression_logs` (impression)와 `collection_interaction_logs` (open) 로그가 best-effort로 기록
    - `experiment_bucket`이 가능한 경우 함께 기록(컬럼 없더라도 UI 영향 없음)

---

## 3) 첫 로그인 온보딩

- **P0 | 첫 로그인 온보딩 진입/완료**
  - **방법**: 신규 계정(온보딩 미완료)으로 로그인
  - **기대 결과**
    - 질문/선택 플로우가 정상 진행
    - 완료 후 홈/프로필에서 선호 태그가 반영되거나(가능한 곳에서) 에러 없이 지나감

- **P1 | 온보딩/선호 태그가 홈 상황 레일 초기 탭에 영향**
  - **방법**: 선호 태그 설정 후 홈 상단 “오늘 어울리는 코스” 확인
  - **기대 결과**
    - 가능한 경우 선호 태그와 겹치는 탭이 초기 선택으로 반영

## 4) 컬렉션 만들기/편집/공개

- **P0 | 컬렉션 생성**
  - **방법**: 새 컬렉션 생성
  - **기대 결과**
    - 생성 성공, 내 컬렉션/관리 화면에서 노출
    - 제목/공개 범위/설명 입력이 유효성에 따라 처리

- **P0 | 컬렉션 편집(메타/태그/커버)**
  - **방법**: cover 이미지 URL 설정/해제, 태그/설명 수정
  - **기대 결과**
    - 저장 성공, 상세/홈 카드에서 반영
    - cover를 비운 경우 자동 대표 커버가 있으면 표시될 수 있음(없으면 기존 그라데이션)

- **P0 | 공개/비공개 전환**
  - **방법**: visibility 전환
  - **기대 결과**
    - 비공개 컬렉션은 타인/비로그인에서 접근 불가(또는 숨김)
    - 공개 컬렉션은 홈/검색/태그 탐색에 노출 가능

---

## 5) 컬렉션 저장/좋아요/공유

- **P0 | 저장/좋아요**
  - **방법**: 컬렉션 상세에서 저장/좋아요(또는 해당 UI가 있는 화면) 동작 확인
  - **기대 결과**
    - 상태 토글이 즉시 반영되고 새로고침 후에도 유지
    - 저장/좋아요 수가 있는 UI는 정상 갱신(또는 최소한 깨지지 않음)

- **P0 | 공유**
  - **방법**: 공유 버튼 → 링크 복사/공유 시도
  - **기대 결과**
    - 공유 성공 시 UX 정상(클립보드/웹 공유)
    - 실패해도 앱이 멈추지 않고 적절한 안내

- **P1 | 공유/클릭 로그(best-effort)**
  - **방법**: 공유 성공 후 Admin insights에서 증가 여부 확인(가능 시)
  - **기대 결과**
    - `collection_interaction_logs`에 `collection_share_success` 기록될 수 있음

---

## 6) 컬렉션 검색

- **P0 | 검색 페이지 진입/검색 결과**
  - **방법**: 컬렉션 검색 페이지 진입 → 키워드 검색
  - **기대 결과**
    - 결과 렌더/스크롤 정상
    - 카드 클릭 시 상세 이동 정상

- **P1 | 검색 결과 카드 커버**
  - **방법**: cover가 없는 컬렉션이 섞인 경우 확인
  - **기대 결과**
    - cover가 있으면 이미지 표시
    - cover가 없으면 자동 대표 커버(가능 시) 또는 그라데이션 fallback

---

## 7) 태그/상황 탐색

- **P0 | 상황 레일 탭 전환**
  - **방법**: Home “오늘 어울리는 코스” 탭 클릭 전환
  - **기대 결과**
    - 탭 전환 시 레일이 정상 바뀜
    - 탭 결과가 없는 경우 칩/섹션이 숨김 처리

- **P1 | 태그 페이지로 더보기**
  - **방법**: “더보기 →” 클릭
  - **기대 결과**
    - 해당 태그 컬렉션 목록 페이지 진입/렌더 정상

---

## 8) 리믹스/Lineage

- **P0 | 리믹스 생성**
  - **방법**: 공개 컬렉션 상세에서 리믹스 CTA(가능 시) → 생성
  - **기대 결과**
    - 내 컬렉션에 복제본 생성
    - lineage(원본 링크/라벨)가 기대대로 표시(가능한 곳에서)

- **P1 | “이 코스를 바탕으로 만들어진 코스” 섹션**
  - **방법**: 원본 상세에서 자식 코스 섹션 확인
  - **기대 결과**
    - 자식 리스트가 있으면 노출, 없으면 숨김
    - 자식 카드 클릭 이동 정상

---

## 9) 체크인 가능 시간/불꽃

- **P0 | 체크인 버튼/토스트**
  - **방법**: 체크인 가능한 시간/불가능한 시간에 각각 시도(가능하면 스테이징/시간대 조절)
  - **기대 결과**
    - 가능 시간: 정상 체크인 처리
    - 불가능 시간: UX 안내/차단이 정상(에러로 깨지지 않음)

- **P1 | 불꽃/실시간 상태 표시**
  - **방법**: Home의 “지금 뜨는 코스” live 라벨/불꽃 관련 UI 확인
  - **기대 결과**
    - 숫자/라벨이 깨지지 않고, 0일 때도 fallback 문구로 자연스럽게 표시

---

## 10) Admin Collection Insights

- **P0 | Admin 접근/데이터 로드**
  - **방법**: admin 계정으로 insights 페이지 진입
  - **기대 결과**
    - 클릭 로그/저장 데이터 로드
    - 테이블 없을 경우 “schema 안내”가 보이고 페이지가 깨지지 않음

- **P0 | 노출 대비 클릭(CTR)**
  - **방법**: CTR 섹션 확인
  - **기대 결과**
    - 섹션별 impressions/clicks/CTR이 계산되어 표시

- **P0 | A/B Guardrails**
  - **방법**: “Bucket 별 CTR 비교” 영역 확인
  - **기대 결과**
    - bucket별 sample size/impressions/clicks/CTR 표시
    - **impressions < 100**이면 “표본 부족” 표시
    - **experiment_bucket 누락 로그 비율**(NULL/빈 값 기반) 표시

## 배포 전 반드시 볼 콘솔/네트워크 에러 목록

### 콘솔(Console)

- **P0**
  - `TypeError`, `ReferenceError` 등 런타임 예외
  - React 렌더 크래시(흰 화면/무한 리렌더)
  - Supabase 권한 오류가 사용자 플로우를 막는 경우(RLS로 인해 필수 데이터가 전부 null)

- **P1**
  - `home_section_impression_logs` / `collection_interaction_logs` insert 실패가 반복적으로 대량 발생
  - Kakao SDK 관련 에러로 홈/지도 진입 자체가 느려지거나 멈추는 경우

### 네트워크(Network)

- **P0**
  - 필수 화면 데이터 fetch 4xx/5xx로 인해 화면이 비거나 동작 불가
  - 동일 endpoint가 **초당 다수 반복 호출**(중복 fetch 폭주)

- **P1**
  - 관측 로그 insert(`home_section_impression_logs`, `collection_interaction_logs`)가 지속적으로 4xx/5xx
    - 단, **best-effort**라 UI가 정상이라면 P1로만 취급하되, 운영 지표가 깨지므로 배포 전 원인 파악 권장

## 우선순위 높은 회귀 테스트 Top 12 (빠른 스모크)

1. **P0** Guest 홈 첫 렌더/검색바 동작
2. **P0** Guest 홈 “지금 뜨는 코스” 카드 클릭 → 상세 이동
3. **P0** Login 홈 진입 + 상단 토글 전환(전체/픽한 사람)
4. **P0** 컬렉션 생성 → 내 컬렉션/상세 진입
5. **P0** 컬렉션 공개/비공개 전환 → 타인/비로그인 접근 확인
6. **P0** 컬렉션 공유(복사/웹 공유) 성공/실패 UX
7. **P0** 컬렉션 검색 → 결과 클릭 이동
8. **P1** cover 없는 컬렉션 카드에서 자동 대표 커버/그라데이션 fallback
9. **P1** Home 상황 레일 탭 전환 + 더보기 링크
10. **P1** 리믹스 생성 + lineage 섹션 노출 확인(있을 때)
11. **P1** Admin insights CTR 섹션 렌더(테이블 없으면 schema 안내)
12. **P1** Bucket guardrails(표본 부족/누락 비율) 표시
